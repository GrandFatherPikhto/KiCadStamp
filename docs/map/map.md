## 2.3. Словарь

- **Ячейка (`cell`)** — абстрактный шаблон (компоненты + медь в своей СК); хранится в `cells:`. Модель:
  `kicadstamp/config/models.py` (`Cell`).
- **Сущность (`entity`)** — постановка ячейки на (кластер, лист); раздел `entities:`.
- **Импринт** — захваченный отпечаток постановки; раздел `imprints:`.
- **mount** — смещение начала ячейки от локального `(0,0)`; `kicadstamp/geometry/cell_anchor.py` (`cell_mount_offset`).
- **Спица** — один компонент/пара внутри цепочки; **цепочка (`chain`)** — раздел `chains:`.
- **`net_traces`** — межкластерная медь, записанная за своей записью; раздел `net_traces:`.
- **`thermal_via_arrays`**, **`points`**, **`clone_placements`**, **`tree_instances`**, **`sheet_templates`** —
  разделы конфига (см. `structures.md`).
- **Реестр (via / track)** — два JSON-файла, ключ `anchor|template|role|index`; путь — `registry_paths_for_config`.
- **UUID записи** — формат 3: идентичность записи = `uuid`; ключ реестра несёт `uuid` (`record_key_part`).
- **Таблица папок** — связь листа схемы и экземпляров; **рабочий набор (`WORKING_SET`)** — `kicadstamp/config_working_set.py`.
- **Дверь платы** — единственный путь к плате `connection.board`; канон `techdocs/me/door.md`.

## 2.4. Где лежат данные

- **Профиль**: `profiles/<имя>/config.sexp` + include-файлы. Читает/пишет — `load_config` / `write_config_file`.
- **`.history/`** — бэкапы при Save; **`.bak`** — резерв при подъёме формата (`upgrade_on_disk.py`).
- **Реестры**: два файла (via / track) рядом с профилем (`registry_paths_for_config`); пишет — `record_created`
  / `reconcile` в `kicadstamp/registry.py`.
- **`gui/gui_state.json`**: помнит контекст ячейки (`gui/cell_edit_context.py`), настройки (`gui/settings.py`).
- **Логи**: GUI-лог-док (`gui/docks/log_panel.py`); диагностика — `kicadstamp/diagnostics/` (вне карты).

# docs/map/ — карта проекта

Карта — подсказка, а не истина: расходится с кодом — прав код, а карту поправить.

- **`index.md`** — указатель, СОБРАННЫЙ ИЗ КОДА: модули (строки всего / кода, первая
  строка docstring, пометка `⚠ >800`), их публичное API, кто кого импортирует (включая
  импорты внутри функций), сторожа `tests/repo/`. Генерируется, руками не правится.
- **`map.md`** — «одно правило — одно место», потоки, словарь, где лежат данные. Черновик
  для приёмки; каждое утверждение со ссылкой `файл:строка`.
- **`structures.md`** — «Что лежит в чём» (модели конфига) по факту прочитанного кода.
- **`contracts.md`** — сквозные договоры (дверь к плате, сокет, один писатель конфига, UUID, i18n, Д8, А0б…):
  суть + где в коде + сторож + канон. Читать ДО задания и ДО приёмки — действуют, даже если задание их не назвало.

## Перегенерация `index.md`

Linux / macOS:
```sh
.venv/bin/python tools/project_map.py
```
Windows:
```bat
.venv\Scripts\python.exe tools\project_map.py
```

Перед заданием сверь SHA в шапке `index.md` с `git rev-parse HEAD`. Отстал — перегенерируй.
Путь вывода — первый аргумент (по умолчанию `docs/map/index.md`); `--root` нужен только
тестам (подложить временное дерево).

Тесты — `tests/repo/test_project_map.py`; оснастка мутаций —
`kicadstamp/diagnostics/deepseek_mutations_project_map_2026_10_05.py`.

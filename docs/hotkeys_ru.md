# Горячие клавиши

Все горячие клавиши GUI KiCadStamp. Список будет расти — полная документация доков/функций —
в [docs/gui_ru.md](gui_ru.md).

Горячие клавиши **переназначаются**: откройте вкладку **Settings** в Detail dock и используйте
группу **Hotkeys** (по одному редактору комбинаций на действие). Переопределения хранятся в
`gui_state.json["hotkeys"]` как `{action_id: shortcut}`; отсутствие записи — значит используется
значение по умолчанию из кода.

| Клавиша | Где действует | Что делает |
|---------|---------------|------------|
| `F2` | Дерево конфигурации (любой лист) | **Rename** — то же самое, что «Rename...» в контекстном меню. |
| `Ctrl+O` | Везде (док Project / меню File) | **Open Root file...** — выбрать корневой конфиг проекта. |
| `Ctrl+N` | Везде (док Project / меню File) | **New Root file...** — создать новый корневой конфиг. |
| `Ctrl+S` | Везде (док Project / меню File) | **Save** — сохранить настройки корня на вкладке Project. |
| `Ctrl+Shift+A` | Док Project | **Add...** — добавить файлы схем в `schematic_files` корня. |
| `Ctrl+Shift+R` | Док Project | **Remove** — удалить выбранный файл схемы. |

В приложении также есть меню **File** (`&File`) в строке меню, построенное ПО ФУНКЦИИ, а не по
доку: **Open**/**New** переиспользуют собственные действия дока Project (одно действие = кнопка +
хоткей + пункт меню — см. `gui/hotkeys.py`), **Recent** — подменю из того же `recent_root_files`,
что и комбобокс Recent дока Project, **Close** — новая операция закрытия текущего проекта (с
защитой от несохранённых изменений, если на вкладке Project есть незакоммиченные правки), а
**&Quit** — выход. Меню **View** (2026-08-27) перечисляет по одному переключаемому пункту на
каждый top-level док, чтобы закрытый док можно было вернуть без перезапуска.
